# LifeCharter Command Dashboard

A beautiful accountability dashboard for Sacred Kaleidoscope Community and the LifeCharter ecosystem.

## Overview

This dashboard tracks:
- **Outcomes** — Results, not activity
- **Actions Taken** — Made vs Shipped
- **Results vs Metrics** — Target, current, source
- **Project Reports** — Every asset, honest status
- **Gap to Thriving Business** — Sequenced, mission-first

## Brand Palette

- **Deep Indigo:** #1F315B — Primary dark, backgrounds
- **Royal Plum:** #5E3B6C — Mystical accent
- **Sacred Teal:** #2E7C83 — Transformation, clarity
- **Warm Gold:** #D4AF63 — Elegance, sacred highlights
- **Ivory Light:** #F6F1E8 — Primary backgrounds
- **Soft Taupe:** #B9A9A9 — Neutral support

## Typography

- **Display:** Cormorant Garamond (serif)
- **Body:** Open Sans (sans-serif)

## Deployment

This site is deployed on Vercel.

## Data Structure

Edit the `DASHBOARD_DATA` object in `index.html` to update:
- Meta information (quarter, notes)
- Outcomes
- Actions
- Metrics
- Projects
- Gap analysis
